공통 화면은 밝은 중립색 배경·청록색 주요 버튼을 사용한다. 확정은 연녹색, 최초 모집은 연노란색, 인원 보충은 연한 붉은색이며 상태 이름을 함께 표시한다. 전체 시간표에는 다른 모임의 전체 참여자 명단을 노출하지 않는다.

가상 표본 날짜는 2026년 9월 23일이며 이름·예약·신고 수는 설명용이다. 모바일 화면은 신청 전이므로 상대를 수락자로 표시하지 않는다. 관리자 화면 역시 휴관 적용 전의 영향 확인 단계다. 시간표 마지막 21:30 영역은 운영 종료로 표시했다.

시스템 명세의 단일 서버·공통 예약 처리 원칙은 화면을 복잡하게 만들지 않는 배경 조건으로 반영했다. DB·서버·작업 큐 등 구현 용어를 제품 화면에 노출하지 않는다.

이미지는 실행 가능한 UI가 아니며 로그인·슬랙·오류·인원 보충·모든 관리자 화면을 포함한 전체 화면 설계가 아니다. 후속 구현에서는 명세의 권한·검증·접근성·반응형 동작을 실제 컴포넌트로 적용한다.

관리자 신규 목업은 초대 발송 전과 권한 회수 전 상태다. 실제 목록에는 초대 만료·최근 변경을 추가하고, 권한 회수 목업의 '최근 활동일'은 명세의 '최근 변경'으로 맞춘다. [관리자 목업 프롬프트·검토 기록](./관리자계정-생성프롬프트-v1.1.md)에 구현 시 보완점을 기록했다.
