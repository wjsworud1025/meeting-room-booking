## 검토 및 구현 시 적용

목록의 활성·초대 대기·비활성 상태, 본인 회수 금지, 초대 수락 전 미활성, 최근 재인증, 회수 후 활성 관리자 수를 확인했다. 05 이미지는 별도 가상 시나리오이며 04와 목록 인원이 다르다.

실제 구현에서는 목록에 명세대로 초대 만료와 최근 변경을 표시한다. 05 이미지의 '최근 활동일'은 '최근 변경'으로 교정한다. 이미지에 생략된 초대 만료·취소 상태, 관리 이력, 초대 수락, 최초 등록·복구 화면의 세부 동작은 F-16·S-14를 따른다. 재인증 코드 자릿수는 인증 제공자의 실제 설정에 맞춘다. 이미지의 버튼 비활성화와 별개로 서버에서 권한·인원·재인증을 검증한다.
