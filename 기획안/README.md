# 회의실 예약 시스템 시각 기획안

[HTML 기획안 열기](./회의실-예약시스템-시각기획안.html)

## 사용법

1. HTML 파일을 Edge 또는 Chrome에서 연다. 서버 설치나 인터넷 연결은 필요하지 않다.
2. 왼쪽 목차(모바일은 상단)를 선택해 섹션을 이동한다.
3. 목업 이미지를 누르면 확대된다. 닫기 버튼 또는 Esc로 돌아온다.
4. 예약 시나리오 탭과 공정성 계산기의 인원·간격을 바꿔 규칙을 비교한다.
5. PC 왼쪽 아래 인쇄 버튼 또는 브라우저 인쇄로 PDF 저장을 선택한다. 인쇄 시 세 가지 예약 시나리오가 모두 표시된다.

## 구성과 전달

운영 원칙, 학생 예약 흐름, 상태·예외, 관리자 업무, 관리자 계정 생명주기, 시스템 아키텍처·명령 처리·알림, 개발 일정·검증 기준을 포함한다. 목업 5종은 HTML 내부에 포함되어 HTML 하나만 전달해도 표시된다. 파일 크기는 약 9.2 MiB다. 원본 명세로 이동하는 링크는 프로젝트 폴더를 함께 전달했을 때만 사용할 수 있다.

명세 v1.1을 요약한 기획 자료이며 실행 가능한 예약 서비스가 아니다. 성능·복구 수치는 목표이고 검증된 실적이 아니다. 상세 구현은 최종개발명세서 3종을 따른다. 이미지의 보완 사항은 계정·권한 섹션에 명시했다.

## 유지보수

`원본/template.html`이 편집 원본이다. `원본/build.py`를 Python으로 실행하면 기존 목업 PNG를 포함하는 최종 HTML을 다시 만든다. 외부 라이브러리는 사용하지 않는다. 이미지 자체는 수정하지 않는다.

## 검증 기록

2026-09-22, 설치된 Edge의 Playwright 자동화로 PC 1440×1000과 모바일 390×844를 확인했다. 목업 5종 로딩, 시나리오 탭·방향키, 75%/30분 거절·60분 통과, 이미지 확대·Esc 닫기, 가로 넘침 없음, 인쇄 모드의 전체 시나리오 표시, 원본 링크를 확인했다. JavaScript 오류와 외부 HTTP 요청은 0건이다. 캡처는 `원본/*-preview.png`에 보관했다. PDF 파일 생성이나 인쇄 페이지별 검수는 이번 산출물 범위에 포함하지 않았다.
